# Unspeakable Today, Un-Happenable Tomorrow

A single-file interactive HTML page.

## What changed

- Replaced the prior assessment page with an essay-and-dialogue layout built from the supplied text
- Added an ergodic conversation section whose empty whitespace wraps the copy around a visible `212121` sequence
- Added a generative cover canvas that reacts to browser-local signals such as viewport, time, motion preference, connection hints, and battery state when available
- Added controls to regenerate the cover image and flatten/restore the whitespace sequence

## Privacy note

The page does **not** use geolocation, camera, microphone, or remote telemetry. The displayed "Alpha Centauri access" value is a synthetic local index derived from browser-available state.
